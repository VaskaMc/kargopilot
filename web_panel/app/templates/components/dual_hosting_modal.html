Öz Serverində İşlət (Self-Hosted)

Tətbiqi öz serverinizdə (və ya lokal Docker mühitində) qurun və ya mövcud server ünvanınıza qoşulun. Bütün məlumatlar yalnız sizdə qalır.

✓ 100% məlumat suverenliyi — şirkətimizə sıfır telemetriya və sıfır FİN ötürülməsi.
✓ Açıq qaynaq koduna tam nəzarət — yerli SQLite WAL və şəxsi şifrələmə açarı.
✓ Korporativ daxili təhlükəsizlik — on-premise və xüsusi şəbəkə tələblərinə uyğun.
🎯 Kimlər üçündür: Tərtibatçılar, dropshipperlər və məlumatını kənara verməyən şirkətlər.
